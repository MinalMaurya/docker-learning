# Docker Learning

A hands-on collection of projects and experiments built while learning Docker and containerization.

This repository documents my journey of understanding Docker through practical implementations, starting with basic container concepts and gradually exploring more advanced topics.

## Projects

### 01. User Profile App

A simple web application built using Node.js, Express.js, and MongoDB that allows users to view and update their profile information.

**Concepts explored:**
- Running MongoDB using Docker containers
- Container networking
- Persistent data storage using Docker volumes
- Managing multiple containers
- Docker Compose fundamentals

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Git and GitHub
